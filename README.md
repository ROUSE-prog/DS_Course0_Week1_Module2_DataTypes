# World Cup Population Analysis Lab

This repository contains the completed lab **Prepare Data for Analyzing the Relationship Between Population and World Cup Performance**.

## Project files

- `data_types_lab.ipynb` — completed Jupyter Notebook
- `data/world_cup_2018.json` — 2018 World Cup match data used by the lab
- `data/country_populations.csv` — country population data
- `build_world_cup_data.py` — optional Python version of the workflow

## Run the notebook

Open `data_types_lab.ipynb` in Jupyter Notebook, JupyterLab, or VS Code and run all cells from top to bottom.

The notebook loads both files from the local `data/` directory and builds `combined_data`, where each 2018 World Cup team has its number of wins and 2018 population.
